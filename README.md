#### 🔐 [enteauth-omarchy-plugin](https://github.com/eds-4d5/enteauth-omarchy-plugin)

> Widget **Ente Auth 2FA** para a barra do Omarchy (Quickshell/QML).

- 📋 Lista códigos 2FA direto na bar
- 🔍 Busca com fundo branco e detecção “Não localizado”
- 🔒 Bloqueio por **PIN de 4 dígitos** (hash SHA256 local)
- ⌨️ Teclado numérico reposicionado — não cobre a barra de busca
- ☕ Atalho Ko-fi no footer do lock screen
- 📸 Screenshots e README bilíngue (PT + EN)
